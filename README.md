# Investment Club UI – Frontend Assessment

## Overview

This is a frontend implementation of the **Investment Club mobile UI** provided as part of an Entry-Level Software Engineer test.  
The project replicates the design using **HTML, CSS, JavaScript, and Bootstrap**, focusing on responsive layout, component-based structure, and interactive elements.

The goal was to create a mobile-app-like experience that works on desktop, tablet, and mobile devices.

---

## 🚀 Features

- **Responsive Design:** Mobile-first layout with Bootstrap grid system.  
- **Hero Section:** User avatar and welcome message styled like the design.  
- **Stats Grid:** Displays user stats with avatar, name, and score values.  
- **Promo Section:** Shows recommendation and guidance message.  
- **Membership Cards:**  
  - FOUNDATION and ECONOMY memberships  
  - Clickable buttons that toggle descriptions using JavaScript  
  - Styled to match the provided color scheme  
- **Footer & Floating Action Button:**  
  - Footer with copyright notice  
  - WhatsApp floating button for potential user action
